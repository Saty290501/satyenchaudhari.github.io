# Satyen Chaudhari — Machine Learning Engineer

A lightweight, responsive personal website presenting my focus areas, selected ML/GenAI projects, engineering background, and technical toolkit.

## Built with

- Semantic HTML
- Responsive CSS
- Small vanilla JavaScript enhancement for the footer year
- No build system or third-party runtime dependencies

## Run locally

Open index.html in a browser. A local static server can also be used:

~~~bash
python -m http.server 8000
~~~

Then visit http://localhost:8000.

## Publish with GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Select **Deploy from a branch**.
3. Choose the main branch and the root folder.
4. Save and use the published URL shown in the Pages settings.
